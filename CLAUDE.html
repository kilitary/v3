What This Repository Is

An Obsidian knowledge vault (vault14.2) containing interdisciplinary research documentation, simulation logs, and utility Python scripts. The primary content is markdown files organized into research domains; the Python scripts are tooling built on top of that content.

Python Scripts

Install dependencies:

pip install -r requirements.txt

Run the markdown-to-HTML converter (converts all .html files and generates index.html):

python convert_to_html.py

Run the response prover mock (analyzes psy-references/mail2fbi.txt and generates a mock response):

python response_prover_mock.py
# or with a custom mail file:
python response_prover_mock.py path/to/mail.txt

Run the grouped-nodes test suite:

python test_response_prover_grouped_nodes.py

Key Architectural Points

convert_to_html.py — MarkdownToHTMLConverter class. Walks all *.html recursively, embeds images as base64 data URIs, rewrites .html links to .html, and produces a searchable index.html. Hardcoded root path /home/runner/work/named/named in __main__ — update when running locally.

response_prover_mock.py — ResponseProverMock class. Loads psy-references/mail2fbi.txt, samples up to 10 sim_log_*.html files from Red&Queen/playground/models_queryer/, runs a verb-logic categorization system (VerbCategory enum), and generates a structured mock response. Core decision flow: _detect_grouped_nodes_scenario() → grouped-nodes branch or standard APPROVE/DENY branch. Output is printed and also saved to tmp/response_prover_output_<timestamp>.html.

Obsidian conventions — Internal links use [[wiki-style]] syntax. Tags are applied via YAML frontmatter or inline #tag. The .obsidian/ directory holds plugin configs (data.json per plugin) and themes. Do not commit plugin binary main.js files unless intentionally updating a plugin.

Copilot Instructions

From .github/copilot-instructions.html: the knowledge system uses a 4-step process (LOAD → ANALYZE with 2–4 random cycles → RELOAD at 51% → OUTPUT) following Red&Queen random shuffle patterns from simulation logs.
